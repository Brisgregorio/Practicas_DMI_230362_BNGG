## Descripción

Este apartado contiene el manual de instalación y configuración de Flutter, un framework de desarrollo multiplataforma que permite crear aplicaciones para dispositivos móviles, web y escritorio utilizando Dart.

El objetivo es documentar los pasos necesarios para instalar las herramientas, configurar el entorno de desarrollo y verificar que Flutter funcione correctamente.

## Herramientas utilizadas

- **Flutter:** Framework para el desarrollo de aplicaciones multiplataforma.
- **Dart:** Lenguaje de programación utilizado por Flutter.
- **Visual Studio Code:** Editor de código para desarrollar aplicaciones.
- **Android Studio:** Herramienta para configurar el SDK de Android y los emuladores.
- **Flutter CLI:** Herramienta de línea de comandos para verificar la instalación y ejecutar proyectos.

## Verificación de la instalación

Después de completar la instalación, se recomienda ejecutar los siguientes comandos en una terminal:

```bash
flutter --version
dart --version
flutter doctor
```

Estos comandos permiten comprobar las versiones instaladas y detectar posibles problemas en la configuración del entorno.
